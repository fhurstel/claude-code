## 1. Technical SEO

### 1.1 Crawlability

| Issue | Severity | Details |
|-------|----------|---------|
| No XML Sitemap | **CRITICAL** | `sitemap.xml` returns 404. Google has no sitemap to discover pages. |
| Crawl-delay: 10 | **HIGH** | robots.txt sets 10-second crawl delay for ALL bots. This drastically slows crawling. Google largely ignores this, but Bing respects it. |
| Auto-generated robots.txt | **MEDIUM** | HestiaCP default — no sitemap reference, no disallow rules for admin/wp-login. |
| No `Sitemap:` directive in robots.txt | **HIGH** | Even if a sitemap existed, robots.txt doesn't reference it. |

**Robots.txt Content:**
```
# hestiacp autogenerated robots.txt
User-agent: *
Crawl-delay: 10
```

**Recommended robots.txt:**
```
User-agent: *
Disallow: /wp-admin/
Allow: /wp-admin/admin-ajax.php

Sitemap: https://www.fijiitsolutions.com/sitemap_index.xml
```
