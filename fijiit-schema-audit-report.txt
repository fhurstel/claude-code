SECTION 2: MISSING SCHEMA OPPORTUNITIES
================================================================================

--- Finding 1: ProfessionalService (replaces Organization) ---
Priority:   CRITICAL
Impact:     Local Pack, Knowledge Panel, Maps integration
Action:     Replace existing Organization with ProfessionalService

  The current Organization schema does not qualify the site for local business
  rich results. ProfessionalService (a subtype of LocalBusiness > Organization)
  tells Google this is a local service provider with a physical location and
  service area, enabling:
    - Google Local Pack (3-pack in search results)
    - Google Maps Knowledge Panel
    - "Near me" search visibility
    - Service area display

  Required properties for Local Pack eligibility:
    - name
    - address (PostalAddress with street, city, state, zip, country)
    - telephone
    - geo (latitude/longitude)
    - url

  Strongly recommended:
    - areaServed (list of cities served)
    - openingHoursSpecification
    - priceRange
    - description
    - hasOfferCatalog (links to Service schema)
    - aggregateRating

  See: fijiit-recommended-schema.jsonld, Block 1

--- Finding 2: Service Schema (one per service) ---
Priority:   HIGH
Impact:     Service-level indexing, enhanced snippets, entity relationships
Action:     Add Service schema to each service page

  The site offers 10 distinct services but has no Service schema. Each service
  page should have its own Service block with:
    - name
    - description
    - serviceType
    - provider (@id reference to ProfessionalService)
    - areaServed
    - url

  This creates a structured service catalog that Google can use to understand
  exactly what the business offers and match it to relevant queries.

  See: fijiit-recommended-schema.jsonld, Blocks 3-12

--- Finding 3: WebSite with SearchAction ---
Priority:   HIGH
Impact:     Sitelinks search box in Google results
Action:     Add WebSite schema with SearchAction to homepage

  If the site has a search function, adding WebSite schema with a SearchAction
  enables the sitelinks search box directly in Google search results.

  See: fijiit-recommended-schema.jsonld, Block 2

--- Finding 4: AggregateRating ---
Priority:   HIGH
Impact:     Star ratings in search results
Action:     Add aggregateRating inside ProfessionalService schema

  If the business has reviews (Google, Yelp, etc.), adding AggregateRating
  can display star ratings in search results. IMPORTANT: The rating data must
  reflect genuine, verifiable reviews. Do not fabricate ratings.

  Example (add inside ProfessionalService block):

    "aggregateRating": {
      "@type": "AggregateRating",
      "ratingValue": "4.8",
      "reviewCount": "47",
      "bestRating": "5",
      "worstRating": "1"
    }

  NOTE: Replace values with actual review data. Google may issue a manual
  action for fake or misleading review markup.

--- Finding 5: FAQPage ---
Priority:   DO NOT IMPLEMENT (unless authority site)
Impact:     N/A for this site
Action:     Skip

  IMPORTANT: As of August 2023, Google restricts FAQ rich results to
  government and healthcare authority websites only. Since Fiji IT Solutions
  is neither, implementing FAQPage schema will NOT produce any rich results
  and is unnecessary. The site may have an FAQ section for user experience,
  but schema markup for it will be ignored by Google.

--- Finding 6: HowTo ---
Priority:   DO NOT IMPLEMENT (deprecated)
Impact:     N/A
Action:     Skip

  IMPORTANT: Google removed HowTo rich results in September 2023. Adding
  HowTo schema will not produce any rich results. Do not implement.

--- Finding 7: Review (individual) ---
Priority:   MEDIUM
Impact:     Review snippets, trust signals
Action:     Add Review schema for displayed testimonials

  If the site displays customer testimonials or reviews, each one should be
  marked up with Review schema nested inside or referencing the
  ProfessionalService. Each Review needs:
    - author (Person with name)
    - reviewRating (Rating with ratingValue)
    - datePublished
    - reviewBody

  Example:

    "review": [
      {
        "@type": "Review",
        "author": {
          "@type": "Person",
          "name": "John D."
        },
        "datePublished": "2025-06-15",
        "reviewRating": {
          "@type": "Rating",
          "ratingValue": "5",
          "bestRating": "5"
        },
        "reviewBody": "Excellent IT support. They resolved our network issues within hours."
      }
    ]

  NOTE: Only mark up reviews that are actually displayed on the page.

--- Finding 8: ServiceArea with GeoCircle ---
Priority:   MEDIUM
Impact:     Improved local search matching
Action:     Alternative to city-by-city areaServed

  As an alternative or supplement to listing individual cities in areaServed,
  a GeoCircle can define the service radius:

    "areaServed": {
      "@type": "GeoCircle",
      "geoMidpoint": {
        "@type": "GeoCoordinates",
        "latitude": 37.5485,
        "longitude": -121.9886
      },
      "geoRadius": "50000"
    }

  The city-by-city approach (used in Block 1) is generally more precise and
  preferred because it explicitly names the cities the business serves.

--- Finding 9: ContactPoint Enhancement ---
Priority:   MEDIUM
Impact:     Knowledge panel contact information
Action:     Add multiple ContactPoint entries

  The existing contactPoint should be expanded to differentiate between
  contact types (customer service vs. technical support vs. sales). Each
  should include:
    - telephone
    - contactType
    - email
    - availableLanguage
    - areaServed
    - contactOption (if applicable, e.g., "TollFree")

  See: fijiit-recommended-schema.jsonld, Block 1 contactPoint array

--- Finding 10: SameAs for Entity Disambiguation ---
Priority:   LOW
Impact:     Knowledge Graph entity recognition
Action:     Ensure all social/directory profiles are in sameAs

  The sameAs array should include all official profiles:
    - Facebook page
    - LinkedIn company page
    - Twitter/X profile
    - Yelp business page
    - Google Business Profile
    - BBB listing
    - Industry directory listings

   9:00-18:00). Update with actual business hours.

   Verify and adjust to the exact business location.
